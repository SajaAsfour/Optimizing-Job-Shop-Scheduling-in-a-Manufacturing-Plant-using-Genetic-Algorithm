# 🏭 ENCS3340: Optimizing Job Shop Scheduling using Genetic Algorithm

## 📌 Overview
This repository contains my implementation of **Project #1: Optimizing Job Shop Scheduling in a Manufacturing Plant** for the **ENCS3340: Artificial Intelligence** course at **Birzeit University**. The project focuses on solving the **Job Shop Scheduling Problem (JSSP)** using a **Genetic Algorithm (GA)** to optimize job sequences and minimize overall production time.

## 🛠 Features
- ✅ **Genetic Algorithm Implementation** for scheduling optimization.
- ✅ **Custom Input Handling:** User-defined jobs and machine configurations.
- ✅ **Gantt Chart Visualization** for scheduling results.
- ✅ **Flexible Testing:** Allows different numbers of machines and job sequences.

## 📂 Contents
- 📜 **Source Code:** Python implementation of the scheduling system.
- 📊 **Gantt Chart Generation:** Visual representation of optimized schedules.
- 📄 **Report:** Explanation of genetic algorithm components (chromosome representation, crossover, mutation, objective function) and test cases.
